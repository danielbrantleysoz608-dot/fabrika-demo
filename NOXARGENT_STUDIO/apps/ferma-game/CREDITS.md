# Авторы и лицензии

## Музыка
Вся фоновая музыка игры — **оригинальная**, написана для «Фермы деда» и генерируется кодом
прямо в браузере (Web Audio API), файл `webapp/js/music.js`:

| Тема | Темп | Тональность | Инструменты | Цикл |
|---|---|---|---|---|
| Весна (март–май) | 96 BPM | до мажор | гитара/укулеле (перебор), флейта, бас, шейкер, мягкий бит | 80 с |
| Лето (июнь–август) | 108 BPM | ре мажор | укулеле, «свисток», бас, шейкер, бит | 71 с |
| Осень (сентябрь–ноябрь) | 86 BPM | ля | гитара, флейта, бас, «щётки» | 89 с |
| Зима (декабрь–февраль) | 72 BPM | соль мажор | колокольчики, гитара, тёплый пэд, бас | 80 с |

* Звук струны — алгоритм Karplus-Strong, мелодии строятся из мажорной пентатоники по аккордам (seed — детерминированно, цикл бесшовный).
* Музыка из чужих игр, популярных песен и сторонних библиотек сэмплов **не используется**.
* Файлов музыки нет — игра не скачивает ни одного мегабайта ради звука.

## Звуки
Все звуки (вжух, монетки, молоток, колокольчик, шелест карточки, «свежий сбор», фанфары) —
синтез в Web Audio API, файл `webapp/js/sfx.js`. Сторонних звуковых файлов нет.

## Шрифты
* Rubik — SIL Open Font License 1.1 (Google Fonts)
* Marck Script — SIL Open Font License 1.1 (Google Fonts)

## Графика
Вся графика — оригинальный SVG, нарисованный кодом (`webapp/js/scene.js`, `farmer.js`, `icons.js`)
по референсам сериала «Ферма с нуля».
