# Экспорт сериала «Деревня деда» для бота

Сюда кладутся два файла (их делает `export_village.py` из проекта сериала после каждого выпуска):

- `village_map.png` — большая карта посёлка (финальное состояние выпуска);
- `villagers.json` — список жителей:

```json
[{"nick": "eduard949219", "platform": "instagram", "x": 1840, "y": 960, "number": 17, "episode": 2, "special": null}]
```

`nick` — нижний регистр, без @; `platform` — instagram / youtube / tiktok или null; `x`, `y` — пиксели на `village_map.png`;
`number` — номер жителя; `episode` — выпуск появления; `special` — особый дом (текст) или null.

Бот перечитывает файлы сам при изменении (перезапуск не нужен). Картинки домов кэшируются в `cache/` (в git не попадает).
